# 初始化：scan | walkthrough

> 模式选择 → [ROUTER.md](../ROUTER.md)。

## Mode A · scan

1. 工作区无 SSOT → 复制 `templates/ssot-starter.json`（**自动**，不对用户讲命令）
2. 扫描旧 CV / 论文 / 结题 / 仓库 → person, engagements, outputs, metrics
3. `source_ids` + `confidence`；冲突 → `conflicts[]` 不擅自裁决
4. 缩写 draft 进 `term_registry`
5. 短报 + 待确认清单（≤10）

## Mode B · walkthrough

按层落盘；**≤3 问/轮**；进度话术见 [workflows/resume.md](resume.md#walkthrough-进度话术-init-时用)。

层：person → engagements（含边界）→ outputs → metrics/constraints → terms（可选）

## 对用户

不需要编程；出错可重来；第 1 轮后应能看到草稿摘要。
